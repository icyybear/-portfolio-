# Personal Portfolio Website

A responsive personal portfolio webpage built using **HTML and CSS**. It introduces me, showcases my projects, and includes a contact form.

## Live Demo

https://icyybear.github.io/YOUR-REPO-NAME/

## Features

- **Navigation menu:** sticky top bar with links that smoothly scroll to each section
- **About section:** short introduction about me and my interests
- **Projects section:** project cards with a hover effect
- **Contact form:** name, email and message fields with built-in validation
- **Responsive design:** adjusts to mobile and desktop screens using CSS Flexbox and media queries

## How to Run Locally

1. Clone the repository:
   ```
   git clone https://github.com/Icyybear/YOUR-REPO-NAME.git
   ```
2. Open the folder:
   ```
   cd YOUR-REPO-NAME
   ```
3. Double-click `index.html` to open it in your browser.

## How to Deploy on GitHub Pages

1. Go to **Settings > Pages** in your repository.
2. Under **Source**, choose **Deploy from a branch**.
3. Select the **main** branch and **/ (root)** folder, then click **Save**.
4. Your site will be live in a minute or two.

## Note on the Contact Form

This form is a front-end layout with validation only. It does not send emails, because that needs a backend or a service such as Formspree.
